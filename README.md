# ระบบจัดการหอพัก

เว็บจัดการหอพัก: ห้องพัก ผู้เช่าและสัญญา จดมิเตอร์น้ำไฟ ออกบิล รับชำระ แจ้งซ่อม หน้าภาพรวม และส่งออก Excel
เปิดใช้งานผ่าน GitHub Pages และเก็บข้อมูลไว้ที่ Supabase (ต้องล็อกอินก่อนใช้)

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด |
| `config.js` | ค่าเชื่อมต่อ Supabase |
| `supabase/schema.sql` | สร้างตารางและสิทธิ์ในฐานข้อมูล (รันครั้งเดียว) |

ถ้ายังไม่ได้ใส่ค่าใน `config.js` เว็บจะเก็บข้อมูลไว้ในเบราว์เซอร์ของเครื่องนั้นแทน

## ตั้งค่าครั้งแรก (ประมาณ 15 นาที)

### 1. สร้างโปรเจกต์ Supabase
1. สมัครที่ https://supabase.com (ใช้บัญชี GitHub หรือ Google ก็ได้)
2. กด **New project** ตั้งชื่อเช่น `dorm` ตั้งรหัสผ่านฐานข้อมูล (จดเก็บไว้) และเลือก Region เป็น **Southeast Asia (Singapore)**
3. รอสร้างเสร็จประมาณ 1–2 นาที

### 2. สร้างตารางข้อมูล
1. เมนูซ้าย **SQL Editor** > **New query**
2. เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งหมดไปวาง
3. แก้บรรทัดล่างสุด `your.email@gmail.com` เป็นอีเมลที่จะใช้ล็อกอิน (ใส่ได้หลายคน บรรทัดละคน)
4. กด **Run** ต้องขึ้นว่า Success

### 3. ตั้งลิงก์เว็บให้ระบบล็อกอิน
1. เมนูซ้าย **Authentication** > **URL Configuration**
2. **Site URL** ใส่ `https://sunsbee-dev.github.io/dorm/`
3. **Redirect URLs** กด Add URL แล้วใส่ `https://sunsbee-dev.github.io/dorm/` เหมือนกัน แล้วกด Save

### 4. ใส่ค่าเชื่อมต่อในเว็บ
1. ใน Supabase กดปุ่ม **Connect** ด้านบน (หรือ **Project Settings** > **API**)
2. คัดลอก **Project URL** และ **anon public key**
3. แก้ไฟล์ `config.js` ใน GitHub (กดไอคอนดินสอ) ใส่สองค่านั้น แล้วกด **Commit changes**

```js
window.DORM_CONFIG = {
  supabaseUrl: 'https://xxxxxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...',
  googleLogin: false
};
```

anon key ใส่ใน repo public ได้ ข้อมูลถูกป้องกันด้วยรายชื่ออีเมลในขั้นที่ 2
ห้ามใส่ **service_role key** หรือรหัสผ่านฐานข้อมูลลงไฟล์ใดๆ ใน repo

### 5. ลองใช้งาน
1. รอ GitHub Pages อัปเดต 1–2 นาที แล้วเปิด https://sunsbee-dev.github.io/dorm/
2. ใส่อีเมล กด **ส่งลิงก์เข้าสู่ระบบทางอีเมล** เปิดอีเมลแล้วกดลิงก์ ระบบจะพากลับมาที่เว็บ
3. เครื่องนั้นจะจำการล็อกอินไว้ ครั้งต่อไปเปิดเว็บก็ใช้ได้เลย

### ย้ายข้อมูลเดิมเข้ามา (ถ้ามี)
ในเว็บเวอร์ชันเดิม ไปที่ **ตั้งค่า** > **ดาวน์โหลดไฟล์สำรอง** แล้วในเว็บใหม่ที่ล็อกอินแล้ว ไปที่ **ตั้งค่า** > **นำเข้าไฟล์สำรอง**

## งานที่ทำเป็นครั้งคราว

**เพิ่มหรือลบคนที่ใช้ระบบได้**: Supabase > **Table Editor** > ตาราง `allowed_users` > **Insert row** ใส่อีเมล (ลบได้ด้วยการลบแถว)

**สำรองข้อมูล**: ในเว็บ ไปที่ **ตั้งค่า** > **ส่งออกเป็น Excel** หรือ **ดาวน์โหลดไฟล์สำรอง** เก็บไว้ในเครื่อง อย่าอัปโหลดไฟล์พวกนี้ขึ้น GitHub เพราะมีข้อมูลผู้เช่า

## ข้อควรรู้เรื่อง Supabase แบบฟรี
- ถ้าไม่มีใครเปิดใช้เว็บเลย **7 วัน** Supabase จะพักโปรเจกต์ไว้ เข้าไปที่ supabase.com แล้วกด **Restore project** ข้อมูลไม่หาย ถ้าใช้งานทุกสัปดาห์จะไม่เจอปัญหานี้
- อีเมลลิงก์เข้าสู่ระบบส่งได้ไม่กี่ฉบับต่อชั่วโมง ปกติล็อกอินครั้งเดียวต่อเครื่องจึงพอ ถ้ามีคนใช้หลายคนพร้อมกันตอนเริ่ม ให้ทยอยล็อกอิน

## เปิดปุ่ม "เข้าสู่ระบบด้วย Google" (ไม่บังคับ)
1. สร้าง OAuth Client ใน Google Cloud Console ตามคู่มือ https://supabase.com/docs/guides/auth/social-login/auth-google
2. Supabase > **Authentication** > **Sign In / Providers** > **Google** เปิดใช้และใส่ Client ID กับ Client Secret
3. แก้ `config.js` เป็น `googleLogin: true`
